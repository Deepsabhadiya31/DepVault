Architecture

How it works

Three isolated stages. Nothing executes. Everything runs locally on your machine.

01
Stage 1

Download safely

Fetches tarballs over HTTPS directly from registry.npmjs.org or pypi.org. Verifies official published checksums (sha256/integrity) and unpacks into an ephemeral sandbox with strict zip-slip and bomb defenses (SEC-1 to SEC-3).

02
Stage 2

Check with rules + local AI

Deterministic AST & regex rules flag install hooks (preinstall, setup.py), credential paths, and network calls. Flagged snippets are passed to a local open-source LLM via Ollama for plain-English synthesis.

03
Stage 3

Allow / Warn / Block

Formula guarantees AI can raise risk but never lower it below rule findings. An ALLOW passes directly to your real package manager. WARN prompts for confirmation. BLOCK aborts immediately before code ever touches disk.

Security Principles

Why trust it

Designed defensively for hostile environments. DepVault treats every incoming package as adversarial.

100% Local AI

Uses 100% local AI inference via Ollama. Only official package registries, OSV.dev, and localhost are ever contacted. Zero cloud APIs, zero telemetry, zero code leaves your machine.

Never executes packages

Safe AST and tar extraction in ephemeral memory. No setup.py, npm install, or build script code is ever run, imported, or compiled during analysis.

Pure Open Source (GPL-3.0)

Transparent rules, public scoring formulas, and verifiable reproducible builds. No paywalled enterprise gates or proprietary cloud dependencies.

Coordinated Disclosure

Strict vulnerability handling with 72-hour acknowledgement and private reporting channels. Read our full policy in SECURITY.md.
